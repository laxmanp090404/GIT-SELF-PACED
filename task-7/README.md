# **Task-7 Cherry-Pick Commands**

### `git cherry-pick <commit-hash>`

* **Function:** Applies a specific commit from another branch to the current branch.
* **Effect:** Creates a new commit with the same changes but a different commit hash.

---
### `git cherry-pick --continue`

* **Function:** Continues the cherry-pick process after resolving conflicts.
* **Effect:** Finalizes the cherry-picked commit.

---

### `git cherry-pick --abort`

* **Function:** Cancels the ongoing cherry-pick operation.
* **Effect:** Restores the repository to the state before cherry-pick started.
